Landing page institucional responsiva com simulador de economia tributária.

## Publicação no GitHub Pages

Em **Settings → Pages**, selecione:

- Source: `Deploy from a branch`
- Branch: `main`
- Pasta: `/(root)`

`https://gouveai5media.github.io/depaulaadvsp/`
